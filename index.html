The problem

Job portals show thousands of results and leave the filtering to the user. Freshers especially can’t tell which roles they actually qualify for, so they apply blindly or give up.

Goal

Make the first screen useful: show roles ranked by fit, explain each match in plain words, and keep search filters one tap away.

Users

Ananya, 20, final-year student.
  • Wants a first internship or job
  • Unsure which skills employers value
  • Needs: clear match reasons, entry-level filter
Rohit, 27, working professional.
  • Wants a better role, little time
  • Searches on his phone after work
  • Needs: fast filters, saved jobs, remote option

User flow

Sign up›Pick skills›See ranked matches›Search and filter›Job details›Save or apply›Track applications

Key design decisions

  • Match ring: a percentage ring on every job so fit is readable at a glance.
  • “Why this match” line: names the skills you share, so the suggestion isn’t a black box.
  • Filters in the sidebar on desktop, stacked on mobile: the same controls at every screen size.
  • Skill chips instead of a long form: setting up a profile takes seconds and updates results live.
  • Accessibility: visible focus states, high-contrast text, 44px-friendly tap targets, light and dark themes.

Tools and process

Research on existing portals, personas, user flow, low-fidelity wireframes, high-fidelity screens, then a clickable prototype (this page). Match scores in the prototype are calculated from skill overlap to show how AI recommendations would behave.

What I learned

Explaining a recommendation matters as much as making it. Users trusted ranked results more once each one told them why it was suggested.
